# M0 D2 结构化输出验证记录

## 验证目标

基于升恒消费金融接口文档的“授信申请”字段定义，验证模型输出进入 Java 系统后，能够依次经过结构化映射、结构校验和业务校验。测试数据全部为合成数据，不代表真实客户或真实交易。

## 来源与范围

- 来源文档：升恒消费金融接口文档，授信申请请求参数章节。
- 本次范围：授信申请字段映射、文档声明的必填字段、日期格式、金额、利率和性别枚举。
- 本次不做：加解密、真实资方调用、SFTP 前置条件、工具循环、向量检索和代码生成。

## 三个核心样例

| 样例 | 处理阶段 | 预期结果 |
|---|---|---|
| 合法完整样例 | 映射 → 结构校验 → 业务校验 | 全部通过 |
| 缺少 `applyAmt` | 映射 → 结构校验 | 映射成功，结构校验失败 |
| 字段齐全但金额为负、利率超范围、证件日期倒置 | 映射 → 结构校验 → 业务校验 | 结构校验通过，业务校验失败 |

另有一个非法 JSON 测试，用于证明映射失败不会进入后续校验。
