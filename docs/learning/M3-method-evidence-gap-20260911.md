## 证据

原始 DOCX 的通用加密/传输说明中写明：最终混合信息“通过 POST 请求发给对方”。4.2 章节自身只包含接口说明、请求地址、请求参数和响应参数，没有独立的 HTTP 方法字段。

## 影响

M3 候选抽取需要同时使用：

1. 4.2 专用证据：接口用途、地址、字段和错误码；
2. 文档通用协议证据：HTTP 方法、加密和传输约束。

当前集合只提供第 1 类证据，所以 DeepSeek 返回“证据不足”是正确结果，Java 不应补填 `POST`。
