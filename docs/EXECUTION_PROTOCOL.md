# 每日执行协议

所有工作会话按本协议执行，避免只依赖对话记忆。`ROADMAP.md` 管阶段顺序，`DAILY_PLAN.md` 管日期任务，`HANDOFF.md` 管当前唯一动作和交接证据。

## 开工前

1. 读取 `docs/HANDOFF.md` 最新交接记录和当前状态。
2. 读取 `docs/ROADMAP.md`，确认当前阶段与任务编号。
3. 读取 `docs/DAILY_PLAN.md` 当日日期段，只执行标记为“今日”的任务。
4. 读取全部 ADR，检查是否有冻结决策冲突。
5. 输出当日任务清单，逐项标记“待完成”，不把“下一步”自动当作“今日”。

## 执行中

- 项目任务、Java 面试任务、AI 学习任务分别记录，不得用项目完成替代面试完成。
- 每项任务必须有结果证据：文件、命令输出、你的回答或复盘记录。
- 未有证据的任务只能标记“未完成”，不能推断为完成。
- 一次只推进一个当前任务；遇到方向问题先记录，不自行扩大范围。

## 收工前

1. 对照当日清单逐项核对完成状态。
2. 分别记录项目、面试、学习和复盘结果。
3. 在 `DAILY_PLAN.md` 写入当天实际结果和未完成项。
4. 在 `HANDOFF.md` 顶部追加交接记录，写明下一步唯一动作。
5. 只有阶段认证通过，才把下一阶段标为可开始。

## 状态定义

`待完成` 表示没有证据；`进行中` 表示已开始但未闭环；`已完成` 表示产物和验证证据齐全；`已认证` 表示学习者完成理解或独立验证，不等于 AI 代跑成功。
