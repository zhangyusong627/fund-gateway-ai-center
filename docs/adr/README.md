## 使用规则

- 开工前读取全部 ADR 标题，确认没有冻结决策冲突。
- 新方向、新技术或范围变化使用新 ADR 记录。
- 不把 ADR 中的历史目标、早期排期或被替代方案当成当前实现状态。
- 当前业务范围以 ADR-011、当前产品文档和 `ROADMAP.md` 共同核对。
