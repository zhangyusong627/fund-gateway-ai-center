# ADR-013：合成资方白名单扩展与历史真实机构名替换

- 日期：2026-09-12
- 状态：已接受
- 决策人：用户（雨松）
- 执行：WorkBuddy

> 本 ADR 涉及的真实机构名一律以占位符 `[OLD_NAME_A]`、`[OLD_NAME_B]` 等形式记录，避免在 ADR 文本本身命中真实机构名；占位符到具体机构名的映射仅在合规审计时由学习者口头补全。

## 背景

ADR-001 第 3 条把合成资方白名单固定为「恒誉 / 云腾 / 衡丰」。M2~M7 实施过程中引入了 `[OLD_NAME_A]`（持牌消费金融公司）与 `[OLD_NAME_B]`（民营银行）两家真实金融机构作为演示文档与评测样本，并在 M3 资方接入助手调用样例的 endpoint 路径里保留了 `[OLD_COMPANY_PREFIX_A]`（前公司内部代号路径前缀）字样。上述命名直接违反 ADR-001 规则 1（不得出现前公司内部系统代号）和规则 3（合成资方白名单）。本 ADR 对历史命名做一次性迁移并明确新白名单。**关于「文档内容是否可真实、机构名称是否必须合成」的边界划分由 ADR-014 补充说明。**

## 决策

1. **合成资方白名单扩展为五个**：恒誉 / 云腾 / 衡丰 / 升恒 / 鼎瑞。其中：
   - **升恒** 是 [OLD_NAME_A]（消费金融公司）的合成名替代，前缀 `shengheng`，docx 文件名 `升恒消费金融接口文档.docx`。
   - **鼎瑞** 是 [OLD_NAME_B]（民营银行）的合成名替代，前缀 `dingrui`，docx 文件名 `鼎瑞银行接口规范.docx`。
2. **历史真实机构名一次性迁移**：所有引用 `[OLD_NAME_A]` / `[OLD_NAME_B]` 及其拼音变体（占位 `[OLD_PINYIN_A]` / `[OLD_PINYIN_B]`）、`[OLD_COMPANY_PREFIX_A]`（endpoint 路径前缀）、`[OLD_COMPANY_NAME]`（前公司中文字面）等字面，在本仓库内全部替换为对应合成名（升恒 / 鼎瑞 / shengheng / dingrui）。迁移对象包括 Java 代码、HTML 前端、文档、HANDOFF、AGENTS、ADR、JSON 数据、Maven 资源、SQL schema、单元测试 fixture。**注意：按 ADR-014，docx 文件内容字段（接口规范、错误码、字段定义等）保持真实接口规范不变，仅文件名与 documentId / chunkId 标识符换成合成名。**
3. **数据库旧记录按方案 A 清零重建**：Docker Compose 启动时 pgvector 中按旧 document_id 写入的索引已通过 `pg_dump` 备份到 `backups/`、`DROP SCHEMA knowledge/guardian CASCADE`、重建 schema 完成；M7 自验收前由学习者用新 documentId 重新上传并跑索引任务。
4. **本地 docx 文件目录同步**：`/Users/zhangyusong/Downloads/求职面试/金融机构标准接口文档/` 下的 `[OLD_NAME_A] 接口文档.docx` 重命名为 `升恒消费金融接口文档.docx`；如有 `[OLD_NAME_B]` 相关文件同步重命名为 `鼎瑞银行接口规范.docx`。按 ADR-014，**仅文件名重命名，docx 文件内容字段保持真实接口规范不变**。本次 ADR 只约束仓库内的命名；本地文件目录的重命名由用户在终端手工执行。
5. **commit 提交但暂不 push**：替换完成后做 `git commit`，提交信息说明 ADR 编号与替换范围；远程推送由用户单独确认，避免在 M7 自验收前引入不可回滚变更。

## 影响

- 任何引用 `shengheng-consumer` / `dingrui-bank-api` / `m2_shengheng_*` 作为 documentId、chunkId 前缀或 endpoint 路径的代码、JSON、文档需要同步替换；本 ADR 的替换是字面替换，不改变业务语义。
- ADR-001 规则 3 的白名单文本同步更新为「恒誉 / 云腾 / 衡丰 / 升恒 / 鼎瑞」。
- 测试用例与 M2 固定评测集的预期输出「机构名引用」同步改为合成资方名；「字段内容」保持真实接口规范（按 ADR-014）。
- ADR-014 生效后，本 ADR 第 1 条与第 4 条的语义被重新解释：第 1 条的命名映射保留；第 4 条的重命名不再要求重写 docx 文件内容字段。

- 提交信息示例：`chore: rename real org names to synthetic per ADR-013`；commit message 本身不得包含真实机构名作为违规描述（仅可使用 `[OLD_NAME_*]` 占位符）。
