# ADR-015：对外项目名称与智能守护主叙事

- 日期：2026-09-13
- 状态：已接受
- 决策人：用户（雨松）

## 背景

“资金网关智能决策中心”能够覆盖仓库和多模块工程，但作为求职项目名称过于抽象，不能直接表达当前已经实现的业务价值。结合 Java AI 市场调研报告，项目需要突出“存量企业系统 AI 化”“异常诊断”“受控治理”和 Java 工程化，而不是泛化为通用 AI 平台。

## 决策

1. 对外项目名称统一为 **资金网关智能守护 Agent**。
2. 对外副标题统一为 **面向资金网关异常诊断与受控治理的 Java AI 应用工程**。
3. “FG-ADC 资金网关智能决策中心”保留为仓库代号和内部工程名称，不再作为简历中的主项目标题。
4. 项目主业务叙事统一为：

   ```text
   指标异常 → Java 窗口聚合与风险识别 → Agent 调查
   → RAG 证据检索 → 结构化诊断报告 → Java 门禁
   → 人工审批 → 模拟治理 → 审计与反馈
   ```

5. “智能守护”包含诊断、建议、审批和模拟治理；当前不得表述为自动治理、真实生产治理或真实生产上线。
6. 知识库是智能守护的证据前置能力，不单独包装成第二个求职项目。

## 范围约束

- 本决策只统一名称、定位和叙事，不新增多 Agent、MCP、Redis、真实监控、生产写操作或新的业务域。
- 项目继续使用 Java 21、Spring Boot、Spring AI、PostgreSQL + pgvector、Redpanda、DeepSeek、本地 BGE 和 Docker Compose 技术基线。
- 项目仍是合成场景验证工程；所有治理动作仅模拟执行。

## 影响

- README、PRD、范围、业务架构、技术架构和求职材料按新名称更新。
- 后续生产化增强必须服务于“证据化异常诊断与受控治理”主链路，并通过单独验收，不以堆叠技术名词为目标。
