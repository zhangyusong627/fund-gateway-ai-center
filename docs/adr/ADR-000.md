## BOM 与生成来源

Initializr 请求：`https://start.spring.io/starter.zip?type=maven-project&language=java&bootVersion=4.1.1&baseDir=initializr&groupId=dev.fgadc&artifactId=fg-app&name=FgAdcApplication&packageName=dev.fgadc.app&packaging=jar&javaVersion=21&dependencies=web`。
原始生成 POM 保存在 `../learning/D1-initializr-pom.xml`。生成的启动类、资源和上下文测试原样保留；父 POM 提升为聚合父工程，新增四个空模块，app 聚合五模块装配。仅 app 打可执行包。使用本机 Maven 3.9.9，不采用生成器可能变化的 wrapper 版本。

Spring AI 的发布 POM 可能声明自己的 Framework 版本；最终解析结果由 Boot BOM 管理，必须以依赖树核对，不能把单个发布 POM 当最终运行版本。

## 环境与服务边界

工程命令显式使用 JDK 21；Maven 3.9.9 位于 `/Users/zhangyusong/tools/maven`，Codex 会话可能不会继承用户终端 PATH，验证时可使用绝对路径。模型 key 仅来自环境变量。

Embedding 选型依据：[阿里云文本向量 API](https://help.aliyun.com/zh/model-studio/text-embedding-synchronous-api)，2026-09-06 读取；支持 text-embedding-v4 的 1024 维与 OpenAI 兼容接口。1024 个 float32 约 4 KiB/向量（不含索引），维度足够与否由 D4 合成检索评测证明。D1 不假称已实测维度；模型标识可能被云厂商更新，D4 起保留调用模型和维度证据，模型或维度改变后必须重建索引。
