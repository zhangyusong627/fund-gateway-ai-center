# ADR-002：采用语义化工程命名

- 日期：2026-09-06
- 状态：已确认，待验证
- 决策：代码标识优先使用完整语义名称；`fund` 是模块前缀，`fundgateway` 是组织包名的一部分。

| 类型 | 名称 |
|---|---|
| 组织包名 | `org.practice.fundgateway` |
| 根项目 | `fund-gateway-ai-center` |
| 模块 | `fund-common`、`fund-knowledge`、`fund-guardian`、`fund-integration`、`fund-application` |
| 启动类 | `FundGatewayDecisionCenterApplication` |
| D1 实验类 | `DeepSeekModelCallExperiment` |

项目目录、根 artifactId 和 Spring 应用名统一为 `fund-gateway-ai-center`。类名、方法名和模块名必须能直接表达职责；缩写只在外部产品简称或协议字段中使用。所有 Java 类和方法注释使用中文，POM 依赖、模块和插件按独立元素分行。此次调整不改变依赖版本、业务范围或运行逻辑。
