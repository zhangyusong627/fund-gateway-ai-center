# ADR-001：命名合规改名（去内部系统代号）

- 日期：2026-09-06
- 状态：已执行并验证（`mvn -B clean verify` 通过）；代码标识命名表由 ADR-002 后续替代
- 决策人：用户（雨松）确认的合规红线；执行：WorkBuddy
- 性质：合规修正，不是技术选型变更。**ADR-000 冻结的版本基线（JDK 21 / Boot 4.1.1 / Spring AI 2.0.1）不受影响。**

## 背景

D1 生成的工程标识沿用了前公司内部系统代号（GFW）。该代号一旦随仓库公开或被面试官点开，会泄露前公司内部系统名，并把项目叙事带向"复刻前公司系统"。这与项目既定红线冲突：不写前公司名、不写内部系统代号、资方一律用合成名（恒誉 / 云腾 / 衡丰），系统层面只说"资金网关"。

## 决策

| 项 | 旧 | 新 |
|---|---|---|
| 仓库目录 | `gfw-ai-decision-center` | `fund-gateway-ai-center` |
| 项目代号 | GFW-ADC | **FG-ADC**（Funding Gateway AI Decision Center，中文：资金网关智能决策助手） |
| Maven groupId | `dev.gfw` | `dev.fgadc` |
| 根 artifactId | `gfw-ai-decision-center` | `funding-gateway-ai-center` |
| 模块 | `gfw-common` / `gfw-knowledge` / `gfw-guardian` / `gfw-integration` / `gfw-app` | `fg-common` / `fg-knowledge` / `fg-guardian` / `fg-integration` / `fg-app`（历史改名）；现行代码命名见 ADR-002 |
| 包名 | `dev.gfw.app` | `dev.fgadc.app` |
| 启动类 | `GfwApplication` | `FgAdcApplication` |

**本 ADR 同时授权对 ADR-000 第 20 行的 Initializr 请求串与 `docs/learning/D1-initializr-pom.xml` 做等价脱敏替换**（只改标识，不改参数含义与取值），历史证据语义不变。

## 规则（后续一律遵守）

1. 代码、注释、文档、提交信息、README、简历与面试材料中，**不得出现 GFW 及任何前公司内部系统代号**。
2. 学习者背景统一表述为：**助贷行业资金网关、对接数百家金融机构的 SPI 接入、Sentinel 熔断限流、Hippo4j 动态线程池、生产问题排查**。不写精确机构数量（简历口径另按 v2.2 第 9 节重新核实）。
3. 合成资方继续只用：恒誉 / 云腾 / 衡丰。

## 验证

`JAVA_HOME=<jdk21> mvn -B clean verify` → BUILD SUCCESS；`FgAdcApplicationTests` 通过；启动日志应用名为 `FgAdcApplication`；全仓库（排除 `target/`、`docs/adr/ADR-000.md`、`docs/learning/`）无 `gfw` / `GFW` 残留。
