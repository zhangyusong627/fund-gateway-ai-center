# ADR-005：本地合成测试数据不做脱敏

## 状态

已接受

## 决策

本项目的本地测试、学习和验证数据全部按合成数据处理。代码、测试证据和本地日志可以保留完整字段，不能因为字段看起来像真实身份信息而擅自脱敏或拒绝测试结果。

生产环境的数据治理另行处理：由敏感词典、日志拦截、加密或访问控制策略决定如何记录和落库，不把生产治理规则提前套到本地合成实验。

## 原因

本地实验的目标是验证完整数据流和规则行为。前缀标记不能证明数据是否合成，模型输出是否满足业务结构也不应由“是否包含合成字样”判断。D2 只验证结构化映射和确定性业务规则。

## 影响

D2 真实模型联调保留完整合成响应，模型是否符合提示词单独作为实验观察结果记录；不再增加基于字段名称或前缀的伪安全门禁。
