# ADR-006：以 ToolCallingManager 作为 D3 验证入口

## 状态

已接受

## 决策

在当前冻结的 Spring AI 2.0.1 依赖中，D3 使用 `org.springframework.ai.model.tool.ToolCallingManager` 和实际存在的工具回调 API 做工具循环实验，不引用本地不存在的 `ToolCallingAdvisor`。

## 证据

本地 `spring-ai-model-2.0.1.jar` 和对应源码中存在 `ToolCallingManager`、`DefaultToolCallingManager` 与 `ToolCallLimitExceededException`，未找到 `ToolCallingAdvisor` 类。

## 影响

D3 先验证工具定义解析、工具执行和步数限制的可用能力；如果需要完整循环编排，将在实验中明确由应用层负责的边界，不擅自升级或替换 Spring AI 版本。
