# ADR-016：智能守护的 Prompt、上下文、记忆与受控 Agent 边界

- 日期：2026-09-14
- 状态：已接受
- 决策人：用户（雨松）

## 决策

1. Prompt 使用仓库内版本化资源管理，模型调用必须记录 `promptName` 和 `promptVersion`。
2. `conversationId` 标识一次会话，`diagnosticTaskId` 标识一次诊断；两者必须绑定，禁止跨任务读取消息。
3. 会话消息是短期记忆；指标快照、规则结果、RAG 引用和工具轨迹是诊断工作记忆；人工审批通过后的诊断才允许形成长期案例记忆。
4. 记忆只辅助恢复上下文，不覆盖当前指标、当前契约版本、RAG 证据或 Java 规则。
5. Agent 由应用层显式编排，最多 3 轮模型判断、3 次只读工具调用；权限、参数、超时、失败和终止状态由 Java 控制。
6. 记忆查询必须经过资方范围、诊断任务归属和权限上下文校验。
7. 摘要失败、证据不足、工具拒绝、超预算和上下文恢复失败时，Agent 停止并进入可审计的失败或人工审核状态。

## 范围

本 ADR 只冻结当前合成场景的学习级闭环，不引入多 Agent、Redis、自动修复或生产级认证和容量承诺。
