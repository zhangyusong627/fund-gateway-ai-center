# 资金网关智能守护 Agent：本期范围与验收

> 内部工程代号：FG-ADC 资金网关智能决策中心

## 做什么

本期只交付两项相互衔接的能力：

- **资方知识库**：管理用户提供的资方接口文档和产品资料，完成版本登记、正文/表格解析、分片、BGE Embedding、pgvector 索引、在线检索、来源引用和检索评测。
- **智能守护 Agent**：接收合成运行指标，经 Redpanda、窗口聚合、Java 规则、风险指纹和冷却后创建少量诊断任务；诊断阶段使用知识库证据和白名单只读工具调用 DeepSeek，生成结构化中文报告，经 Java 门禁后展示或转人工审核，审批通过后只做模拟治理。

`fund-integration` 已有的 SPI/资方接入助手保持现状，不作为本期新增交付。知识库和智能守护共享本地 BGE Embedding、PostgreSQL + pgvector 和可追溯证据，通过 Docker Compose 复现。

## 不做什么

不做 SPI/资方接入助手扩展、DTO 生成、真实资方接入、模型方法体生成、通用代码生成、复杂隔离执行平台、Redis、真实监控、生产写操作、自动修复、模型训练、预测平台、多 Agent、Flink、Kubernetes、微服务平台或生产级容量承诺。

## 验收是什么

- `mvn -B verify` 通过，知识库管理入口和智能守护应用可独立健康检查。
- 文档离线索引、在线检索、引用和固定集评测完整可复现。
- “用信申请”候选规范必须有来源，未经 Java 校验和人工确认不能发布。
- 高频指标经窗口、规则、去重和冷却后只产生少量诊断任务。
- Agent 只使用白名单只读工具和 RAG；结构、证据、规则、权限、中文门禁有效。
- 已发布接口规范可成为诊断证据，候选版本不可见。
- Docker Compose 启动 PostgreSQL/pgvector、Redpanda 和本期应用并完成合成验收。
- 每阶段分别记录已运行、已理解和已独立验证。
